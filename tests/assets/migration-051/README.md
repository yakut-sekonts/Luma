# Stable 0.5.1 migration fixture

Created on 2026-10-24 by the actual packaged 0.5.1 executable, source
`d113495cb1d92bf8232e0a6943d972c9fbf0e01a`, executable SHA-256
`9c2ae0582ed8647c8180f5f40d225f3a0ec86be6e8e9dad3005afa65afa67f5d`.
The preserved app passed `codesign --verify --deep --strict`. This is ad-hoc
identity evidence, not Apple notarization.

Both DNGs come from `tests/assets/generate_dng.py:create_dng(orientation=6)`;
the WebP is the project's original `tests/assets/images/quadrants.webp`.
There are no user photographs or credentials. The two DNG sources intentionally
have identical bytes but distinct catalog identities and edit documents.

The stable app created all three assets in one isolated catalog, in filename
order, with `--test-edit SOURCE --test-exposure .35 --test-export OUTPUT.png`.
Additional flags were `--test-complete-masks` for `01-complete.DNG`,
`--test-develop --test-advanced --test-local-masks` for `02-global-local.DNG`,
and `--test-develop --test-local-masks` for `03-common.webp`.
Each creation was followed by a fresh stable process with `--test-restore .35`,
the same additional flags and a second export; each PNG was byte-identical.
These CLI acceptance flags run the real decoder, catalog and export pipeline.

`fixture.json` contains the actual schema-11 SQLite definitions and all rows,
ordered by every column. Only the owned `original_path` prefix was normalized to
`@ORIGINALS@`. Runtime setup restores that prefix to a fresh owned directory;
it inserts the recorded rows before installing the original triggers and checks
SQL integrity, foreign keys and the exact reconstructed snapshot.

`UX-P10-DAT-004` exercises the real schema migration, opens all three photos
through Library, compares decoded legacy masks and exported sRGB pixels to these
historical PNGs, then exits cleanly and restarts in a separate process. Independent
post-exit audits require every historical column/value, original checksum,
pre-migration backup, valid current documents and restart idempotence. Only the
specified mask-format migration and new migration records may differ. The fixture
has no saved edit versions or collections; it makes no coverage claim for them.

The PNG files are immutable historical output, not regenerated by the new renderer.
Source and PNG size/SHA-256 entries are recorded in the manifest. The unit test's
minimal schema-21 control exercises auditor rejection only; it is not migration
or application evidence.
