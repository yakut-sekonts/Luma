# Luma 0.9.0 — internal qualification candidate

This is an unpublished development candidate for the upcoming 1.0.0 release.
The public stable release remains 0.5.1. This installer is used only for isolated
installation, migration, model delivery and update qualification; it does not
mean that the final quality gate has passed.

The current implementation includes Library/catalog management, RAW and common
image import, non-destructive Develop adjustments and local masks, presets/XMP,
batch editing, export, eight interface languages, zoom/Metal preview, local AI
models, HDR/Panorama, metadata, relink and catalog backup/restore.

The package targets macOS 14 or later on Apple Silicon and includes its Qt runtime,
Denoise/Sky models and third-party licenses. Check the included BUILD_INFO.json and
SHA256SUMS to identify the exact build. No Intel build is provided.

Distribution is open source on GitHub. This candidate uses an ad-hoc signature and
is not notarized by Apple. For a trusted downloaded copy, macOS may require a
per-application approval in System Settings → Privacy & Security → Open Anyway
after the first launch attempt. Do not disable Gatekeeper globally.

Installation and update tests use isolated owned catalogs. The final release and
public Sparkle feed remain blocked until the required qualification is complete;
see docs/FINAL_1_0_READINESS.md in the source repository for actual results and gaps.
