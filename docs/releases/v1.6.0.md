# Apertone 1.6.0

Apertone 1.6.0 improves source reconstruction and HDR handling while keeping the
editing pipeline local and non-destructive. It also adds an editable Enhance
operation and exposes structured decode diagnostics for inspecting the active
image path.

## RAW Pipeline 2.0

- Reconstruct Bayer RAW with a deterministic two-pass edge-aware algorithm.
- Choose green interpolation from local sensor gradients and reconstruct chroma
  from color differences to reduce false color along hard edges.
- Preserve the original sensor samples and linear highlight headroom.
- Report the active decoder, reconstruction, CFA, color path, sensor geometry,
  black/white levels and samples at or above sensor white through typed
  diagnostics.

## Adaptive HDR

- Decode Adaptive HDR JPEG/HEIF gain maps and ISO HDR images into the existing
  scene-linear working space.
- Apply optional preview-only HDR tone mapping through the shared CPU/Metal
  display transform while histogram, clipping warnings and export keep the
  original scene-linear values.
- Export Adaptive HDR HEIC on macOS 15 or later with an SDR-compatible base and
  a verified ISO gain map.

Adaptive HDR HEIC is lossy and does not promise exact scene-linear sample round
trips. Transparent areas are flattened against black.

## Editable Enhance

- Add Enhance as an editable Quick Look layer in one Undo step.
- Persist provider name, provider version, model identity and digest when a
  compatible model exists.
- Use an explicit deterministic CPU fallback for the current histogram-based
  provider. The bundled denoise network is not reused because its pixel-output
  contract cannot produce editable Develop parameters.
- Keep saved Enhance layers self-contained for preview, export and future
  restoration.

## Install

Requires macOS 14 or later on Apple Silicon. Adaptive HDR HEIC export requires
macOS 15 or later. Download `Apertone-1.6.0-macos-arm64.dmg`, drag Apertone to
Applications and open it. The open-source build is ad-hoc signed and is not
Apple-notarized. If Gatekeeper blocks the first launch, Control-click Apertone,
choose Open, then confirm Open.

Existing installations receive 1.6.0 through the update bell. The release also
provides the Sparkle-signed ZIP, `appcast.xml`, SHA-256 manifest and build
provenance.
